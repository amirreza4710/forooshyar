# ADR-011 — Forooshyar Plus Product Naming

**Status:** Accepted
**Date:** 2026-09-29
**Component:** Product / Governance
**Supersedes:** product naming in ADR-009 and ADR-010

## Context

The approved integration imported useful Bazarak capabilities into the existing sales platform. The user selected one product identity rather than operating Bazarak and Forooshyar as separate products.

## Decision

- The official product name is **Forooshyar Plus / فروشیار پلاس**.
- Bazarak is a historical source and capability label for Field Operations and Automation, not an independent product.
- Farakhorasan remains the platform-level boundary where it is required by prior architecture decisions.
- Existing technical identifiers, package names, paths, database names, deployment names, repository slug, and Git remote remain unchanged.

## Consequences

Canonical product, roadmap, PRD, ADR, status, and navigation documents use Forooshyar Plus. Historical records retain their original names where needed for traceability. Any technical rename requires a separate migration plan and acceptance review.
